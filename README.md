## Why MP3 to WAV?

WAV is a standard, typically uncompressed audio format that is accepted by almost all audio editors and production tools. Converting an MP3 to WAV makes the file easier to edit and use in these programs.

Please note: MP3 is a lossy format, so converting to WAV does not restore audio quality that was already removed. The WAV file will sound the same as the MP3 but will be much larger. If you have the original recording, use that for the best quality.
